PROJECTS / 02

Selected work

01
CLOUD BACKEND · UNIVERSITY RESEARCH

CRS-RAG / Versioned decision intelligence

Built a stateful Python research backend that tracks construction-site facts, regulatory evidence, and the decisions that depend on them. When inputs change, affected assessments are selectively reevaluated instead of starting over.

Scenario inputs→Versioned state→Rule checks→Audit trail
PythonFlaskPostgreSQLAzure
Read technical details ↓

Engineering problem

Updates to site conditions can invalidate only part of a previous assessment. A useful system must preserve what changed, what evidence was used, and which conclusions need reevaluation.

My implementation

Relational scenario versions, condition history, dependency-aware invalidation, optimistic concurrency, hypothetical branches, and a curated retrieval catalog of 12 OSHA provisions with six narrow deterministic rule checks. A research API was deployed to Azure.

Scope

The current checks and text parsing are deterministic. This is not a production OSHA compliance system or a verified LLM-driven assistant.

02
DEEP LEARNING · MEDICAL IMAGING

LVEFangio / Cardiac video modeling

Researched spatiotemporal deep learning approaches to estimate cardiac ejection fraction from angiography video, combining 3D convolutional encoders with spatial and temporal Transformer components.

4.7MAE in LVEF percentage points, as reported in the research poster
PyTorch3D ResNetTransformersVideo ML
Read technical details ↓

Engineering problem

Angiography is variable-length video. Continuous cardiac-function estimation requires capturing movement and context, not only individual frames.

Research work

Video preparation, architecture experiments, and model evaluation. The poster reports Pearson r = 0.496 and a 4.7-point MAE. The research received a first-place poster presentation award at the 2025 Michigan Tech HRI Student Forum.

Scope

Exploratory research, not clinical validation. The reported metrics should not be interpreted as an independently validated medical device.

AI AGENTS · HACKATHON TEAM PROJECT

PolyWatch / Evidence-linked investigation

Helped build an agentic research tool for prediction markets. The workflow combines market data, news, wallet activity, and statistical investigation in a traceable interface rather than a black-box answer.

1stPlace, hackathon project · 26 investigative tools in the architecture
Agent orchestrationAPIsJacTool use
Read technical details ↓

Engineering problem

Investigations involve separate market, wallet, and news sources. Without intermediate evidence, an agent's conclusion is difficult to verify.

What the team built

A tool-oriented investigative flow with a live trace and branching tree for reviewing observations and source references. The 26 tools cover multiple evidence categories.

Scope

Team-built hackathon prototype, not a validated detector of insider trading or proof of wrongdoing.

COMPUTER VISION · SOFTWARE SYSTEMS

SiteObserver / Safety intelligence prototype

Developed a local-first construction-site simulation and safety-monitoring interface with explainable proximity checks, incident history, REST endpoints, and optional video detection and tracking.

Site simulation / video→Hazard engine→Dashboard & logs
FastAPIReactTypeScriptYOLO11
Read technical details ↓

Engineering problem

Visualize site interactions and make unsafe proximity or restricted-zone events inspectable in a reproducible development environment.

Implementation

Interactive local map, synthetic deterministic trajectories, a four-second constant-velocity proximity horizon, incident logging, typed REST APIs, Docker workflows, and optional recorded-video analysis using pretrained detection/tracking.

Scope

The pretrained vision model is not construction-specific, and this prototype is not a certified safety or predictive system.
